# BPMS Generator

This repository contains a BPMS generator with models for each evaluation case.

## Evaluation Cases

Each case includes the generator implementation and corresponding models:

- **Case 1:** [Absence Request (most representative example used throughout the paper)](https://github.com/pavliuc75/thesis_public/tree/absence_request_UPDATED)
- **Case 2:** [Loan Request](https://github.com/pavliuc75/thesis_public/tree/loan_request_UPDATED)
- **Case 3:** [Error Handling](https://github.com/pavliuc75/thesis_public/tree/error_handling_UPDATED)
- **Case 4:** [Second Step](https://github.com/pavliuc75/thesis_public/tree/second_step_UPDATED)

Instructions for running the generator are included in the README file of each branch.

**Note:** These branches were refactored and cleaned up the day after the thesis deadline. The original versions can be found in the branch selector.
